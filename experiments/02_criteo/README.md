- 현재 노트북: `study.ipynb` — 새 표본에서 H3/H4를 검증하는 실험
- 공유 입력: `../../data/criteo/`
- 재사용 코드: `shared/criteo/`
- 현재 실험 결과·설정: `results/`

`results/cache/`는 로컬에만 보관하고 Git에서 제외합니다.
