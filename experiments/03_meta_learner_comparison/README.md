# S/T/X-Learner 등 방법 비교

향후 여러 인과추론 방법을 같은 조건에서 비교할 실험 공간입니다. 아직 실행하지 않았습니다.

- 입력 데이터: `../../data/`에서 선택하며 원본을 복사하지 않습니다.
- 노트북: 비교 설계를 정한 뒤 `comparison.ipynb`에 작성합니다.
- 재사용 코드: `shared/`.
- 결과: 실행 시 이 폴더의 `results/`에 저장합니다.

방법 비교에서는 같은 처치·성과·피처·학습/검증/평가 분할과 평가 지표를 고정하고,
S/T/X, DML·DR 등의 차이를 확인합니다. 기준은 결과를 보기 전에 정합니다.
